What this tool does

Polyline Curve Builder combines the old open/closed fit/spline tools into one command. It reads the current selection, orders connected model/detail curves into a single chain, automatically detects whether the chain is open or closed, and creates new curve output.

Original curves are preserved. The command creates new output curves and does not delete the selected source lines.

The main production fit path uses AutoCAD Core Console to run the real PEDIT Fit operation, then converts the returned curve-fit vertices and DXF bulges into editable Revit Arc and Line elements.

Quick start

  1. Select connected model lines or detail lines. If nothing is selected, the command prompts you to pick curve elements.
  2. Run Polyline Curve Builder.
  3. Review the detected chain type and endpoint gap in the dialog.
  4. Choose Model Lines or Detail Lines.
  5. Choose Fit Curve for AutoCAD PEDIT Fit tangent arcs, or Spline Curve for a NURBS control-point spline.
  6. Click OK. The command creates the new curve elements and prints a pyRevit report.

Fit Curve vs Spline Curve

Fit Curve

Runs the AutoCAD-style PEDIT Fit process when AutoCAD Core Console is available.

  • Best match to AutoCAD curve-fit polyline behavior.
  • Creates Revit Arc and Line pieces from DXF bulge data.
  • Falls back to a native G1 biarc approximation if AutoCAD fails.

Spline Curve

Uses the ordered vertices as control points for NURBS-style output.

  • Open spline uses native Revit NurbSpline creation.
  • Closed spline uses the Dynamo control-point workflow.
  • Useful when control-point spline behavior is preferred over arc-fit behavior.

Which should I choose?

For the curve that should match AutoCAD PEDIT Fit, choose Fit Curve. For a spline controlled by the selected vertices, choose Spline Curve.

Requirements and installation

Revit / pyRevit

  • Designed for Revit 2022-2027 with pyRevit IronPython 2.7.
  • Place the script in the pyRevit pushbutton folder as _script.py.
  • Place this help file in the same pushbutton folder as help.html if you want pyRevit to open it as command help.

AutoCAD Core Console

For the most accurate Fit Curve result, AutoCAD Core Console should be installed. The command looks for accoreconsole.exe in common AutoCAD install paths. You can also set one of these environment variables to point directly to the executable:

ACCORECONSOLE_EXE=C:\Program Files\Autodesk\AutoCAD 2025\accoreconsole.exe
AUTOCAD_CORE_CONSOLE=C:\Program Files\Autodesk\AutoCAD 2025\accoreconsole.exe
If AutoCAD Core Console is not found or fails, Fit Curve still runs using the native G1 biarc fallback, but the shape may not exactly match AutoCAD PEDIT Fit.

Production notes

  • The command uses transactions and rolls back if curve creation fails.
  • Warnings are suppressed during creation where possible, then summarized in the pyRevit output.
  • Progress bars are cancellable during chain ordering, curve building, and curve creation.
  • AutoCAD bridge files are temporary and are cleaned after processing in the production version.
Tip: For repeatable results, keep selected source lines coplanar and avoid very short segments, stacked duplicate lines, or endpoints that nearly touch but do not actually connect.
